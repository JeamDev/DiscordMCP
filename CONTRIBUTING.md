# Contributing

Use Node.js 22.12 or newer. Run `npm ci` and `npm run check` before submitting a change. Tests use synthetic data and must not connect to a live Discord server. Never include .env, runtime state, logs, real conversations, user IDs or deployment-specific scripts in a contribution.
